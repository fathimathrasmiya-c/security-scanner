# AI Security Scanner

An end-to-end security automation platform that integrates static analysis with LLMs to identify, triage, and remediate vulnerabilities. Developed a Python-based CLI backend using **Semgrep** and **Anthropic (Claude)** for automated triage and fix generation. Built cross-platform interfaces including a **React/Vite** web dashboard and a **Flutter** mobile app for real-time security monitoring and finding management. Optimized the remediation workflow by implementing a robust parsing engine for AI-generated code fixes and synchronizing complex security metadata across the entire technical stack.

### **Core Technologies**
*   **Languages:** Python, JavaScript (React), Dart (Flutter), SQL.
*   **Tools & Frameworks:** Semgrep, Anthropic Claude API, Vite, Provider, Node.js, Flask.
*   **Security:** OWASP Top 10, Static Application Security Testing (SAST), Vulnerability Triage, Automated Remediation.
